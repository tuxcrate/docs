# Tuxcrate

Open-source apps.
Containerized and ready to run.

Tuxcrate packages open-source applications as container images.
Find an image, check its runtime requirements, and choose a release tag for your deployment.

## Container images

The [container image catalog](containers/index.md) lists published versions, release tracks, immutable image revisions, and all current GHCR tags.

Each image page explains how to run the application and what its tags mean.
Check the configuration and host requirements before starting a container.

## Found a bug?

Open an issue in the affected image's source repository, linked from its image page.
Include the image tag or digest, your platform, steps to reproduce the problem, and relevant logs.
Remove credentials and other sensitive information before posting.
For problems with this website, use the [website issue tracker](https://github.com/tuxcrate/website/issues).

## Have a suggestion?

Start a [GitHub Discussion](https://github.com/orgs/tuxcrate/discussions/new/choose) to describe your idea and the problem it would solve.
Include an example of how you would use it.

## Contributing

You can contribute fixes, documentation improvements, or changes to container images.
Start with the [maintainer guides](maintainers/index.md) for setup and development instructions, then submit a pull request to the relevant repository.
For larger changes, open an issue first to discuss the approach.
