# Maintainer guides

Keep repository READMEs short and use these guides for shared setup instructions,
development, and day-to-day operations.

- [Container releases](container-releases.md): workflow setup, metadata, build conventions, tags, publication, and failure recovery.
- [Container runtime tests](container-tests.md): shared user validation, host-side smoke hooks, and local image testing.
- [Adding a repository](adding-a-repository.md): contribution checklist for new container and non-container repositories.
- [Dependency updates](dependency-updates.md): shared Renovate presets.
- [GitHub infrastructure](github-infrastructure.md): OpenTofu validation, repository imports, and branch protection.
- [Website development](website.md): image pages, version tables, local development, and deployment.
